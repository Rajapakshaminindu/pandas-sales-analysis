# Pandas Sales Analysis Project

This is a beginner-friendly pandas project for learning data analysis and creating a small GitHub portfolio project.

## Project goal
Use a small sales dataset to:
- clean the data
- calculate revenue
- summarize by product and region
- save processed results as CSV files

## Files
- `sales_data.csv` - raw dataset
- `pandas_sales_analysis.py` - pandas script
- `clean_sales_data.csv` - cleaned data
- `product_summary.csv` - product revenue summary
- `region_summary.csv` - revenue by region

## Run the project
```bash
python pandas_sales_analysis.py
```

## Learn these pandas concepts
- `read_csv()`
- `head()`
- `isnull()`
- `dropna()`
- `to_numeric()`
- `groupby()`
- `sum()`
- `sort_values()`
- `to_csv()`
